# Changelog

## v0.6

Initial public Windows release.

- Windows system-tray application
- HamThings and BrandMeister live monitoring
- Compact draggable popup with configurable opacity
- BrandMeister orange / HamThings blue network styling
- Active TGs shown before inactive TGs
- Numeric ascending TG order within each state
- 3-second popup expiry refresh cycle
- Configurable TG filters
- Optional BrandMeister private-call metadata filter
- Configurable retention for ended transmissions
- Optional callsign and node display
- Start with Windows support
