# Third-party services and components

TGWatch for Windows currently has no external NuGet package dependencies beyond the .NET / Windows platform libraries used by the project.

The application consumes live data from independent third-party services:

| Service | Use |
|---|---|
| HamThings | Live DMR activity feed |
| BrandMeister | Live DMR activity feed |

HamThings and BrandMeister retain all rights to their names, trademarks, services, infrastructure and data. TGWatch for Windows is not affiliated with, sponsored by, or officially endorsed by either service.

The .NET runtime and Windows platform components retain their respective Microsoft licenses and notices.
